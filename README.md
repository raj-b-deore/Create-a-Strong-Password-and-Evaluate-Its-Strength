## 🔍 Feedback from Password Strength Tool

- Short passwords are easily breakable.
- Use of symbols improves strength.
- Combination of uppercase and lowercase letters increases complexity.
- Inclusion of numbers enhances unpredictability.
- Password length above 12 characters significantly increases security.

---

## 🛡️ Best Practices for Creating Strong Passwords

- Use at least **12–16 characters**
- Include:
  - Uppercase letters (A–Z)
  - Lowercase letters (a–z)
  - Numbers (0–9)
  - Special characters (!, @, #, $, %, ^, & , *, etc.)
- Avoid dictionary words
- Do not use personal information
- Use passphrases instead of simple words
- Change passwords periodically

---

## ⚠️ Common Password Attacks

### 1. Brute Force Attack
In this attack, hackers try every possible combination of characters until the correct password is found.

### 2. Dictionary Attack
In this attack, attackers use a list of common passwords or words from the dictionary to guess the password.

---

## 📌 Impact of Password Complexity on Security

- Simple passwords can be cracked within seconds.
- Increasing password length increases cracking time exponentially.
- Using a mix of characters makes passwords resistant to brute force attacks.
- Complex passwords reduce the risk of unauthorized access.
- Strong passwords protect sensitive information from cyber threats.

---

## ✅ Tips Learned from Evaluation

- Password length matters more than complexity alone.
- Avoid predictable patterns.
- Use passphrases for better memorability.
- Never reuse passwords across platforms.
- Use a password manager if necessary.

---

## 🏁 Conclusion

This task demonstrated how password complexity and length significantly improve security against common password attacks such as brute force and dictionary attacks. It also highlighted the importance of creating strong, unpredictable passwords to protect sensitive information from unauthorized access.
